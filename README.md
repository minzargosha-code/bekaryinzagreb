# BekaryInZagreb 🥐

Сайт-визитка пекарни в Загребе с редактируемым каталогом товаров.

## О проекте

Одностраничный сайт пекарни в тёплой тёмно-оранжевой цветовой гамме, 
рассчитанный на аудиторию 20–40 лет. Включает встроенную панель 
управления каталогом, которая позволяет добавлять, редактировать 
и удалять товары без правки кода.

## Возможности

- Каталог товаров с ценами, категориями и описанием
- Панель управления каталогом (иконка в левом верхнем углу)
- Автоматическое сохранение изменений
- Блок с информацией о пекарне: адрес, телефон, часы работы
- Адаптивная вёрстка под мобильные устройства

## Технологии

- HTML5
- CSS3
- JavaScript (vanilla)

## Как открыть

Скачайте файл `bekary-in-zagreb.html` и откройте его в любом браузере — 
установка не требуется.
